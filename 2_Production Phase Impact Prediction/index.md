# Machine Learning Background

## What is Machine Learning

**Machine learning** is a branch of artificial intelligence that enables computers to learn from data rather than relying solely on explicitly programmed rules. During training, a machine learning model is shown many examples so it can identify patterns and relationships in the data.  Once training is complete, the model can analyze new, similar data to make predictions or solve problems based on what it has learned.  Because the model learns from its training data, it generally performs best on data that is similar to the examples it was trained on. In this phase, you will use an **artificial neural network**, a type of machine learning model inspired by the structure of the human brain that is particularly effective at recognizing patterns and learning complex mathematical relationships.
